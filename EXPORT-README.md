# MOEX QBR Tool — экспорт проекта

Этот архив содержит исходный код интерактивного концепт-прототипа MOEX QBR Tool, созданного в ChatGPT.

## Что входит в архив

- текущий frontend-прототип QBR Tool;
- исходный код React/TypeScript;
- локальные UI-компоненты;
- стили и графический знак MOEX;
- package-lock с зафиксированными версиями зависимостей;
- тесты и скрипты сборки;
- мастер-промпт на дальнейшую разработку полноценного сервиса с Supabase в `docs/MASTER-PROMPT-SUPABASE.md`.

## Текущий статус проекта

Экспортируемая версия является интерактивным frontend-прототипом. Данные предзаполнены и изменяются в состоянии браузера. Supabase, постоянная база данных, серверная авторизация и AI API пока не подключены.

Спецификация для реализации полноценной версии с Supabase включена в каталог `docs`.

## Требования

- Node.js 22.13 или новее;
- npm;
- Linux или совместимое окружение для штатных скриптов сборки.

## Локальный запуск

```bash
npm ci
npm run dev
```

После запуска открыть адрес, указанный Vite в терминале.

## Проверка production-сборки

```bash
npm run build
npm test
```

Команда `npm test` повторно выполняет сборку, а затем запускает проверки интерфейса и метаданных.

## Основные файлы

- `app/page.tsx` — интерфейс и логика прототипа;
- `app/globals.css` — глобальные стили;
- `app/layout.tsx` — метаданные приложения;
- `components/ui` — используемые UI-компоненты;
- `public/favicon.svg` — локальный графический знак;
- `docs/MASTER-PROMPT-SUPABASE.md` — техническое задание на полноценный frontend и backend.

## Размещение

Опубликованная версия на момент экспорта:

https://qbr-team-review-mx.vivalarust.chatgpt.site

Файл `.openai/hosting.json` содержит идентификатор исходного сайта, но не содержит секретов или ключей. Если проект импортируется как новый независимый сайт, зарегистрируйте новый проект и замените его hosting-конфигурацию средствами выбранной платформы.

## Что исключено

В архив намеренно не включены:

- история Git;
- `node_modules`;
- временные и сборочные каталоги;
- локальные логи;
- файлы окружения `.env`;
- пароли, токены и API-ключи.
